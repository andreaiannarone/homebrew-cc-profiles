# Homebrew tap for cc-profiles

[cc-profiles](https://github.com/andreaiannarone/cc-profiles) is a local web UI to manage multiple Claude Code profiles.

```sh
brew install andreaiannarone/cc-profiles/cc-profiles
cc-profiles open
```

Update with `brew upgrade cc-profiles`, or from the app (About → Check for updates).

The formula is written by the release script of cc-profiles at every release: do not edit it by hand. Documentation: https://cc-profiles.andreaia.com
